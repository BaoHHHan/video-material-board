使用说明

一行一个视频，模型按需添加

将截图拖到“视频截图”格子中，或批量添加截图来创建多行。在对应行的模型区域拖入多张图片，即可一次添加多个模型。

ID 与数量可以直接修改

上传时默认取文件名（不含扩展名）作为 ID。每个模型的数量独立填写，默认 1；视频行会汇总模型种类和总数量。已手动修改的 ID 在替换图片时会保留。

点击查看，拖拽替换

点击已有图片可放大查看。拖入新图片或使用“替换”更换图片。删除视频、模型或参考图后，可在底部提示中撤销。

自动保存在本机

内容存放在当前浏览器，不会同步到其他设备或浏览器。线上版与下载的本地版各自保存数据；本地版可断网打开。请勿清除浏览器的网站数据，重要原图请另外保留。
