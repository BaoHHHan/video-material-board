# 素材工作台

一个无依赖的本地优先网页工具，用表格整理视频截图、视频 ID、模型 ID、模型参考图和数量。

## 使用

直接打开 `index.html`，或通过静态网站托管访问。无需安装、账号或后端服务。

- 每行对应一个视频，支持添加、复制、删除和撤销删除。
- 拖入视频截图自动填写文件名作为视频 ID，也可手动修改。
- 批量添加视频截图，一张图片创建一行。
- 每个视频可添加多个模型，每个模型独立设置 ID、参考图和数量。
- 模型图片支持一次拖入多张，文件名自动成为模型 ID。
- 已手动修改的 ID 在替换图片时保持原值。
- 模型数量默认 1，支持 0–999999 的整数，按行汇总种类与总数量。
- 顶部可放置整体原素材参考图，支持折叠和删除。
- 点击图片放大预览；拖入图片或点击替换来更新。
- 切换完成状态，按状态筛选，搜索视频或模型 ID。
- 修改与图片自动保存到当前浏览器的 IndexedDB；保存失败会明确提示。
- 支持多窗口修改冲突检测，防止静默覆盖。
- 清单标题可编辑。网页内可下载完整单文件离线版本。
- 单选或多选视频导出文本，也可点击行右侧按钮单独导出。
- 表头复选框全选当前筛选结果，筛选时保留已选项并显示隐藏的已选数量。
- 导出按表格顺序排列，使用视频 ID 作为标题（未填则按原行序号命名），按模板生成模型 ID 和数量。
- 导出前预览，一键复制；浏览器阻止自动复制时支持选中文本手动复制。
- 模型为空或 ID 缺失时提示补全，不会静默遗漏；完成状态与导出选择互不影响。

支持 JPG、PNG、WebP、GIF、AVIF 和 BMP 图片，单张不超过 25 MB。AVIF 等格式是否可解码取决于浏览器。

## 数据边界

内容和图片只保存在当前浏览器，不发送到任何服务器。没有统计脚本、第三方字体或外部资源依赖。

不同设备、浏览器、域名和本地文件环境之间不自动同步数据。清除网站数据、浏览器回收存储空间或删除浏览器配置可能导致数据丢失，请保留重要原图。本地版和线上版的数据各自独立。

导出文本格式：

```text
* 核心玩法录屏搭配

视频一：
* 使用以下模型ID
* M_01654 21个，M_01666 21个，M_00126 21个
视频二：
* 使用以下模型ID
* M_01449 15个，M_00107 15个，M_01489 15个，M_01230 15个
```

选择状态仅用于本次导出，不改变视频完成状态，也不影响已保存的素材。

## 开发与部署

全部代码位于 `index.html`，无需构建。可用任意静态服务器预览，也可在 GitHub Pages 中将 `main` 分支根目录设为发布源。

仓库仅包含工具代码，不含用户上传图片或清单内容。
